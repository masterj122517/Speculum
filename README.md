# Accountability Mirror (审判之镜)

> "The truth will set you free, but first it will piss you off."

A psychological tool for radical self-honesty. Face your reflection and surround yourself with your truths.

## Features

- **Live Mirror Feed** - Full-screen camera with grayscale/contrast filter for a raw, serious aesthetic
- **Dynamic Sticky Notes** - Click anywhere to create, double-click to edit, drag to reposition
- **Rip-off Animation** - Delete notes with a satisfying paper-tearing effect
- **Persistence** - All notes survive across sessions via localStorage
- **Immersive UI** - Controls auto-hide after 3 seconds, leaving only you and your truths

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## How to Use

1. **Face the Truth** - Click the button to enable camera access
2. **Create Notes** - Click anywhere on the mirror to place a new sticky note
3. **Write Your Truth** - Type directly on the note
4. **Drag & Drop** - Move notes anywhere with physics-based dragging
5. **Delete** - Click the red button to rip off a note when you've conquered it
6. **Edit** - Double-click any note to modify its content

## Note Colors

- **Yellow** - Post-it classic for goals and intentions
- **Gray** - Brutalist for harsh truths and weaknesses
- **Orange** - Warning for urgent matters

## Deployment

Deploy to Vercel or Netlify directly from this repository. No build configuration needed.
